## Build command

```bash
cd amr_ws
colcon build
source install/setup.bash
```

## Launch commands

```bash
# Robot model in RViz2
ros2 launch mini_amr_description display.launch.py

# Robot bringup (model + simulated odometry + LiDAR)
ros2 launch mini_amr_bringup robot.launch.py

# Teleoperation (separate terminal)
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# SLAM mapping (slam_toolbox)
ros2 launch mini_amr_bringup slam_demo.launch.py

# Autonomous navigation (Nav2)
ros2 launch mini_amr_navigation navigation.launch.py

# Send a navigation goal
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: map}, pose: {position: {x: 1.0, y: 0.8}, orientation: {w: 1.0}}}}"
```
